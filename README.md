# ShopManager PRO — PHP/MySQL

نظام إدارة مبيعات ومخزون وفواتير يعمل على استضافة PHP + MySQL.

## المتطلبات
- PHP 8.0 أو أحدث
- MySQL 5.7+/MariaDB
- Apache أو Nginx
- PDO MySQL مفعّل

## التثبيت
1. أنشئ قاعدة بيانات أو افتح phpMyAdmin.
2. استورد `install.sql`.
3. افتح `config.php` وعدّل:
   DB_HOST / DB_NAME / DB_USER / DB_PASS
4. ارفع الملفات إلى الاستضافة.
5. افتح `login.php`.

بيانات الدخول التجريبية:
- المستخدم: admin
- كلمة المرور: password

غيّر كلمة المرور فورًا قبل البيع/النشر.

## المميزات
- تسجيل دخول وصلاحيات
- لوحة تحكم
- نقطة بيع POS
- منتجات ومخزون وتنبيه نقص
- عملاء وديون
- مصروفات
- تقارير حسب التاريخ
- إدارة مستخدمين للمدير
- حماية CSRF واستعلامات PDO المجهزة
- واجهة عربية RTL ومتجاوبة للجوال

## قبل البيع التجاري
يُفضّل إضافة:
- تعديل وحذف المنتجات والعملاء
- تسديد الديون
- فاتورة PDF وطباعة حرارية
- إعدادات المتجر والعملة والضريبة
- نسخ احتياطي من لوحة الإدارة
- سجل نشاط المستخدمين
- ترخيص/تفعيل المنتج
- اختبارات أمنية ووظيفية شاملة
